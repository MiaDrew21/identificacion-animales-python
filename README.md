# Identificación de animales mediante reglas y predicados

## Descripción

Proyecto didáctico que transcribe hechos de identificación de animales a Python. Utiliza un diccionario para almacenar hechos y tuplas para representar reglas. Incluye una ontología en Markdown con un diagrama Mermaid.

## Archivos

- `main.py`: hechos, reglas y proceso de inferencia.
- `ontologia.md`: explicación y gráfico de relaciones.
- `README.md`: descripción e instrucciones del proyecto.


## Ejecución

```bash
python main.py
```

Los datos y reglas son ejemplos educativos basados en la actividad de clase.
